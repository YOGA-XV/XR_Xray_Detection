# 阶段5：XR-Plus 与增强候选版本记录

## 1. 阶段5定位

阶段5用于确定 `YOLOv8n-XR-Plus` 及其增强候选版本。当前命名约定如下：

```text
XR-Nano = PCN + EGI
XR-Lite = PCN + EGI + EMA-Lite + AIFI-Lite
XR-Plus = PCN + EGI + EMA-Lite + AIFI-Lite + P2-Lite
```

其中 `PCN` 和 `EGI` 由数据配置与训练/预测开关控制；模型 YAML 负责结构部分。

阶段3离线增强仍然暂时跳过，最后再统一验证。

## 2. 已有模型文件

```text
G:/XR_Xray_Detection/ultralytics/cfg/models/v8/yolov8n-xr-lite.yaml
G:/XR_Xray_Detection/ultralytics/cfg/models/v8/yolov8n-xr-plus.yaml
G:/XR_Xray_Detection/ultralytics/cfg/models/v8/yolov8n-xr-p2lite.yaml
```

说明：

- `yolov8n-xr-lite.yaml` 是 `XR-Lite`。
- `yolov8n-xr-plus.yaml` 是正式 `XR-Plus`。
- `yolov8n-xr-p2lite.yaml` 是 `XR-Nano + P2-Lite`，只作为 P2-only 辅助消融，不代表 Plus。

## 3. 新增 XR-Plus-v2 / v3 / v4

你允许 `XR-Plus` 参数量提高到 `3.6M-4M`，因此新增三个增强候选版本：

```text
XR-Plus-v2: 强化 P2 分支，用 C2f 替代原先极轻的 DWConv + Conv P2 融合。
XR-Plus-v3: 加宽 P3 检测分支，并加入 C2fEMALite。
XR-Plus-v4: 同时强化 P2 分支与加宽 P3 EMA，是组合增强版。
```

新增模型文件：

```text
G:/XR_Xray_Detection/ultralytics/cfg/models/v8/yolov8n-xr-plus-v2.yaml
G:/XR_Xray_Detection/ultralytics/cfg/models/v8/yolov8n-xr-plus-v3.yaml
G:/XR_Xray_Detection/ultralytics/cfg/models/v8/yolov8n-xr-plus-v4.yaml
```

结构检查得到的参数量：

```text
XR-Lite     3,438,612 params
XR-Plus     3,305,792 params
XR-Plus-v2  3,622,624 params
XR-Plus-v3  3,503,040 params
XR-Plus-v4  3,846,784 params
```

v2 和 v4 已进入 `3.6M-4M` 预算区间。v3 略低于 3.6M，但它是独立验证 P3 加宽 EMA 的必要消融，应保留。


## 12. 判定规则

优先保留满足以下条件的版本：

- `AP-small` 或 `Recall-small` 明显高于 XR-Lite / XR-Plus；
- `AP-thin` 不明显下降；
- `mAP50:95` 不明显低于 XR-Nano；
- 参数量不超过 4M；
- FPS 和显存代价可接受。

如果 v2/v3/v4 中只有 AP-small 提升但 mAP 或 AP-thin 明显下降，则该版本可作为论文消融，不建议作为主模型。
