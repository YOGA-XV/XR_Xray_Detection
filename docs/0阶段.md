# 0阶段：冻结实验协议与数据统计

## 1. 阶段目标

0阶段的目标是把后续所有实验的基础规则固定下来，避免在训练结果出来之后再调整数据划分、指标定义或增强边界。该阶段全权参考 `docs/完整版试验设计方案.md`，主要对应其中：

- 第 5 节：评价指标体系；
- 第 6 节：训练策略；
- 第 13 节：最低实验配置与高质量配置；
- 第 14 节：结果判断标准；
- 第 15 节：最终推荐实验路线。

本阶段不训练模型，只完成实验协议冻结、SPXray 配置固定、可复现数据统计脚本和第一批 SPXray 数据统计结果。

## 4. 冻结的数据增强边界

增强策略只允许用于训练阶段：

- Mosaic；
- MixUp；
- Copy-Paste；
- BGM-XR；
- Mix-Paste-XR；
- BLT-Mix。

验证集和测试集必须保持原始图像与原始标签，不允许使用离线增强后的 val/test 作为正式评估集。

当前本地存在 `datasets/SPXray_BLT_Mix`，后续只能把其中训练部分作为训练增强数据来源，不能把增强后的 val/test 作为正式验证或测试集。

## 5. 冻结的评价指标定义

### 5.1 基础检测指标

所有实验至少报告：

| 指标 | 定义 |
| --- | --- |
| Precision | `TP / (TP + FP)` |
| Recall | `TP / (TP + FN)` |
| AP50 | IoU=0.50 时的 AP |
| AP75 | IoU=0.75 时的 AP |
| mAP50 | 所有类别 AP50 的平均值 |
| mAP50:95 | IoU=0.50:0.95 多阈值平均 AP |

主指标固定为 `mAP50:95`，`mAP50` 只作为辅助指标。

### 5.2 小目标指标

目标面积使用 YOLO bbox 的归一化面积：

```text
area = w * h
```

固定划分：

| 类型 | 定义 |
| --- | --- |
| Small | `area < 0.01` |
| Medium | `0.01 <= area < 0.05` |
| Large | `area >= 0.05` |

报告：

- AP-small；
- AP-medium；
- AP-large；
- Recall-small。

### 5.3 细长目标指标

细长程度使用 bbox 长宽比：

```text
r = max(w, h) / min(w, h)
```

固定定义：

```text
Thin object: r > 3
```

报告：

- AP-thin；
- Recall-thin。

Knife、Scissors、Wrench、Bullet、Plier 只作为典型细长类别辅助分析，不作为 AP-thin 的定义依据。

### 5.4 遮挡与隐藏指标

| 数据集 | 指标定义 |
| --- | --- |
| PIDray | 使用官方 Easy / Hard / Hidden 测试子集，报告 Hidden AP 和 Hidden Recall |
| OPIXray | 使用官方遮挡等级，报告 Heavy Occlusion AP 和 Heavy Occlusion Recall |
| SPXray | 如无官方 hidden 标注，不命名为 Hidden AP；只使用 bbox 重叠代理指标，命名为 Overlap AP |

SPXray 的重叠代理指标固定为：

```text
overlap_ratio_i = max_j Area(b_i intersection b_j) / Area(b_i)
```

| 指标 | 定义 |
| --- | --- |
| AP-overlap@0.3 | `overlap_ratio_i >= 0.3` 的目标 AP |
| AP-heavy-overlap@0.5 | `overlap_ratio_i >= 0.5` 的目标 AP |

## 6. 冻结的统一训练设置

| 项目 | 固定规则 |
| --- | --- |
| Input size | 默认 `640x640` |
| Epochs | SPXray 300；PIDray 300；OPIXray 300 |
| Batch size | 根据显存选取，但同一组对比必须一致 |
| Optimizer | SGD 或 AdamW，同一组对比必须一致 |
| Initial LR | SGD: 0.01；AdamW: 0.001 |
| LR schedule | Cosine decay |
| Warmup epochs | 3 |
| Weight decay | 0.0005 |
| Mosaic | 开启，最后 10-20 epoch 关闭 |
| MixUp | 默认关闭，仅在增强消融中启用 |
| Copy-Paste | 默认关闭，仅在增强消融中启用 |
| BLT-Mix | 本文主增强，仅用于训练阶段 |
| Random seed | 主要结果至少 3 个 seed |
| NMS IoU | 同一组对比固定为 0.6 或 0.7 |
| Confidence threshold | mAP 使用全阈值扫描；可视化默认 0.25 |

主要结果最终报告 `mean ± std`。pilot 阶段允许先跑单 seed 判断方向，但不能作为最终论文结论。

## 8. 统计脚本说明

新增脚本：

```text
scripts/check_dataset_stats.py
```

脚本功能：

1. 读取 YOLO 格式数据集；
2. 统计 train/val/test 图像数、标签数、缺失标签数；
3. 统计每类实例数；
4. 统计每类图像数；
5. 按固定 `area` 阈值统计 small/medium/large；
6. 按固定 `r > 3` 统计 thin 目标；
7. 输出 bbox area 直方图；
8. 输出 aspect ratio 直方图；
9. 输出 JSON 和 CSV，方便论文表格与后续脚本复用。

运行命令：

```powershell
python scripts/check_dataset_stats.py --data configs/datasets/SPXray.yaml --output runs/dataset_stats/SPXray
```

输出文件：

| 文件 | 内容 |
| --- | --- |
| `runs/dataset_stats/SPXray/summary.json` | 数据集总体和各 split 汇总 |
| `runs/dataset_stats/SPXray/split_summary.csv` | train/val/test 图像数、标签数、实例数、尺度和细长统计 |
| `runs/dataset_stats/SPXray/class_distribution.csv` | 每类实例数和每类图像数 |
| `runs/dataset_stats/SPXray/bbox_area_histogram.csv` | bbox 相对面积分布 |
| `runs/dataset_stats/SPXray/aspect_ratio_histogram.csv` | bbox 长宽比分布 |
