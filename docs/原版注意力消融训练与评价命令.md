# 原版注意力消融训练与评价命令

本文档对应 `最终实验表清单.md` 中的 `表 11. 注意力模块消融`，用于训练和评价以下 7 个消融模型：

| 消融项 | 模型配置 | 训练输出名 | 参数量 |
| --- | --- | --- | ---: |
| SE | `ultralytics/cfg/models/v8/yolov8n-xr-nano-se.yaml` | `nano_se` | 3.17M |
| CBAM | `ultralytics/cfg/models/v8/yolov8n-xr-nano-cbam.yaml` | `nano_cbam` | 3.24M |
| nano+原版 EMA | `ultralytics/cfg/models/v8/yolov8n-xr-nano-original-ema.yaml` | `nano_original_ema` | 3.03M |
| nano+原版 AIFI | `ultralytics/cfg/models/v8/yolov8n-xr-nano-original-aifi.yaml` | `nano_original_aifi` | 3.80M |
| nano+原版 EMA + AIFI-Lite | `ultralytics/cfg/models/v8/yolov8n-xr-nano-original-ema-aifi-lite.yaml` | `nano_original_ema_aifi_lite` | 3.35M |
| nano+EMA-Lite + 原版 AIFI | `ultralytics/cfg/models/v8/yolov8n-xr-nano-ema-lite-original-aifi.yaml` | `nano_ema_lite_original_aifi` | 3.91M |
| nano+原版 EMA + 原版 AIFI | `ultralytics/cfg/models/v8/yolov8n-xr-nano-original-ema-original-aifi.yaml` | `nano_original_ema_original_aifi` | 3.82M |

说明：

1. 所有模型统一使用 `configs/datasets/SPXray_pcn_egi.yaml`。
2. 所有模型均为 4 通道输入，训练时保留 `PCN + EGI`。
3. 训练命令统一设置 `patience=0`，不启用早停。
4. 如果原版 AIFI 显存不足，优先把 `batch=16` 改为 `batch=8`，其他参数不变。
5. 训练完成后，先跑验证集评价；需要正式测试集结果时，再跑 `split='test'`。

------

## 1. 一键顺序训练使用方法

推荐优先使用批处理脚本一次性顺序训练 7 个注意力消融模型。脚本会从第 1 个模型开始依次执行，某一个模型训练失败时会立即停止，避免后续结果混乱。

在 Anaconda Prompt、PowerShell 或 CMD 中执行：

```bat
cd /d G:\XR_Xray_Detection
scripts\run_attention_ablation_train_all.bat
```

该脚本默认设置如下：

| 项目 | 设置 |
| --- | --- |
| Conda 环境 | `pg_moe` |
| 数据配置 | `G:/XR_Xray_Detection/configs/datasets/SPXray_pcn_egi.yaml` |
| 预训练权重 | `G:/XR_Xray_Detection/yolov8n.pt` |
| 输出目录 | `G:/XR_Xray_Detection/runs/train_attention_ablation` |
| 训练轮数 | `epochs=400` |
| 早停机制 | `patience=0`，不启用早停 |
| Batch | `batch=16` |
| GPU | `device=0` |
| workers | `workers=4` |
| 确定性训练 | `deterministic=False`，用于降低原版注意力消融的训练耗时 |

脚本会按以下顺序训练：

1. `nano_se`
2. `nano_cbam`
3. `nano_original_ema`
4. `nano_original_aifi`
5. `nano_original_ema_aifi_lite`
6. `nano_ema_lite_original_aifi`
7. `nano_original_ema_original_aifi`

当前批处理脚本会调用 `scripts/run_attention_ablation_train_all.py` 统一调度 7 个模型。该 Python 调度器会自动检查 `runs/train_attention_ablation/<训练输出名>/weights/best.pt` 和 `results.csv`：如果某个模型已经完整跑完 400 轮，会自动跳过该模型并继续后续模型。若需要强制重跑已完成模型，可直接执行：

```powershell
conda run --no-capture-output -n pg_moe python scripts\run_attention_ablation_train_all.py --rerun-completed
```

训练完成后，权重会分别保存在：

```text
G:/XR_Xray_Detection/runs/train_attention_ablation/<训练输出名>/weights/best.pt
```

如果中途失败，先查看控制台最后一个失败模型的报错；修正后可以重新运行整个脚本，或只执行下面对应模型的单独训练命令。

## 5. 回填规则

训练和评价完成后，把结果回填到：

- `最终实验表清单.md` 的 `表 11. 注意力模块消融`
- 需要记录训练过程时，同步更新 `过程表 1. 实验运行登记表`
- 需要记录评价过程时，同步更新 `过程表 2. 评估与指标导出登记表`

建议优先比较：

1. `mAP50:95`
2. `AP-small`
3. `AP-thin`
4. `FPS`
5. 参数量和 GFLOPs

若 `原版 AIFI` 只带来很小精度提升但 FPS 明显下降，则保留为上限对照，不作为主模型。
