下面给你一份**完整、点列式、十分详细的模型体系设计方案**。我会按照“论文方法章节 + 代码实现方案 + 后续消融实验”的粒度来写。

模型建议命名为：

> **YOLOv8n-XR-Lite：面向伪色 X 射线安检图像的边缘与遮挡感知轻量化检测模型**

英文可以写成：

> **YOLOv8n-XR-Lite: An Edge- and Occlusion-Aware Lightweight Detector for Prohibited Item Detection in Pseudo-color X-ray Security Images**

# 1. 总体模型设计目标

## 1.1 任务目标

你的任务不是普通自然图像检测，而是：

> 在伪色 X 射线安检图像中检测违禁品，尤其是严重重叠、隐藏、边缘模糊、小目标和细长目标。

主要检测类别为 SPXray / PIDray 类别体系中的 12 类：

1. Baton
2. Plier
3. Hammer
4. Powerbank
5. Scissors
6. Wrench
7. Gun
8. Bullet
9. Sprayer
10. HandCuffs
11. Knife
12. Lighter

------

## 1.2 模型设计核心矛盾

你的模型需要同时满足：

| 需求                | 难点                                       |
| ------------------- | ------------------------------------------ |
| 提高检测精度        | X 射线图像重叠严重，边缘弱，纹理少         |
| 提高隐藏目标召回    | 目标经常被其他物体覆盖或透明叠加           |
| 保持轻量实时        | 不能盲目堆 Transformer、大注意力或大检测头 |
| 适应伪色图像        | 颜色不稳定，不能过度依赖材质颜色           |
| 适应小目标/细长目标 | Bullet、Knife、Scissors 等容易漏检         |

所以模型设计原则是：

> **不把颜色当核心判别依据，而是把“边缘结构 + 遮挡上下文 + 多尺度轻量特征融合”作为主要创新点。**

# 3. 模块 1：PCN 伪色归一化模块

## 3.1 模块名称

> **PCN：Pseudo-color Normalization**

中文：

> **伪色归一化模块**

------

## 3.2 设计动机

X 射线安检图像中的伪色不是自然颜色，也不是稳定的材料标签。它受以下因素影响：

1. 安检设备型号；
2. 设备内部 LUT 映射；
3. 物体厚度；
4. 材料吸收率；
5. 多物体透明叠加；
6. 后处理增强算法；
7. 图像压缩和存储格式。

所以你之前验证“用颜色区分材质效果很差”是合理的。

PCN 的目的不是让模型利用颜色区分材质，而是：

> **降低不同图像、不同设备、不同伪色映射之间的分布偏移，让模型更关注结构和形状。**

------

## 3.3 输入输出

### 输入

[
$$
I \in \mathbb{R}^{H \times W \times 3}
$$
]

即原始 RGB 伪色 X 射线图像。

### 输出

[
$$
I' \in \mathbb{R}^{H \times W \times 3}
$$
]

即归一化后的伪色图像。

------

## 3.4 推荐实现方式

建议使用**分通道鲁棒百分位归一化**。

对每个通道 (
$$
c \in {R,G,B}
$$
)，计算：

[
$$
p_{low}^{c}=P_1(I_c)
$$
]

[
$$
p_{high}^{c}=P_{99}(I_c)
$$
]

其中：

- (P_1)：第 1 百分位；
- (P_{99})：第 99 百分位。

然后归一化：

[
$$
I_c' = \text{clip}\left(\frac{I_c - p_{low}^{c}}{p_{high}^{c}-p_{low}^{c}+\epsilon}, 0, 1\right)
$$
]

最后再映射到 0–255 或保持 0–1，取决于你的训练管线。

------

## 3.5 为什么不用普通 Min-Max

普通 Min-Max：

[
$$
I_c' = \frac{I_c - \min(I_c)}{\max(I_c)-\min(I_c)}
$$
]

问题是：

1. 对异常亮点敏感；
2. 对设备噪声敏感；
3. 对局部过曝或压缩伪影敏感。

百分位归一化更稳定。

------

## 3.6 论文中可以这样写

> 为降低不同安检设备及不同伪色映射带来的颜色分布偏移，本文首先采用基于百分位的伪色归一化策略。该策略不显式建模颜色与材料之间的映射关系，而是抑制伪色强度分布差异，使后续网络更加关注目标的结构边缘和空间上下文。

------

## 3.7 是否作为网络层

PCN 可以有两种实现方式：

| 实现方式       | 优点                 | 缺点       |
| -------------- | -------------------- | ---------- |
| 数据预处理     | 简单、无参数、推理快 | 不可学习   |
| 网络内归一化层 | 可端到端             | 复杂度略高 |

建议你采用：

> **数据预处理方式。**

原因：

1. 简单；
2. 轻量；
3. 不增加参数；
4. 易复现；
5. 适合论文消融。

------

# 4. 模块 2：EGI 边缘引导输入模块

## 4.1 模块名称

> **EGI：Edge-Guided Input**

中文：

> **边缘引导输入模块**

------

## 4.2 设计动机

X 射线安检图像具有几个典型特点：

1. 目标纹理弱；
2. 颜色不稳定；
3. 多物体透明重叠；
4. 目标轮廓经常被背景干扰；
5. 刀、剪刀、扳手、子弹等类别更依赖几何结构；
6. 伪色材质信息在严重叠加时不可靠。

所以，与其依赖颜色，不如显式引入：

> **边缘、轮廓、梯度结构。**

EGI 的核心思想是：

> 在 RGB 伪色图像之外，额外输入一张结构边缘图，让模型在最早阶段就能感知目标轮廓。

------

## 4.3 输入输出

### 输入

归一化后的伪色图像：

[
$$
I' \in \mathbb{R}^{H \times W \times 3}
$$
]

### 输出

四通道输入：

[
$$
X = \text{Concat}(I'_R, I'_G, I'_B, E)
$$
]

其中：

[
$$
X \in \mathbb{R}^{H \times W \times 4}
$$
]

(E) 是边缘图。

------

## 4.4 边缘图生成方式

建议使用 **Scharr 算子**。

先将伪色图转灰度：

[
$$
G = 0.299R + 0.587G + 0.114B
$$
]

然后计算水平和垂直梯度：

[
$$
E_x = \text{Scharr}_x(G)
$$
]

[
$$
E_y = \text{Scharr}_y(G)
$$
]

边缘强度：

[
$$
E = \sqrt{E_x^2 + E_y^2}
$$
]

归一化：

[
$$
E' = \frac{E - \min(E)}{\max(E)-\min(E)+\epsilon}
$$
]

最终输入：

[
$$
X = [R', G', B', E']
$$
]

------

## 4.5 为什么推荐 Scharr

| 算子           | 优点                           | 缺点               |
| -------------- | ------------------------------ | ------------------ |
| Sobel          | 简单、常用                     | 对细微边缘略弱     |
| Scharr         | 对细小边缘更敏感，方向响应更好 | 略比 Sobel 复杂    |
| Canny          | 边缘清晰                       | 阈值敏感，不稳定   |
| Laplacian      | 二阶边缘明显                   | 对噪声敏感         |
| Learnable Edge | 可学习                         | 增加参数，解释性弱 |

建议主模型使用：

> **Scharr Edge Map**

消融实验中比较 Sobel、Scharr、Canny、Laplacian。

------

## 4.6 YOLOv8 输入层修改

YOLOv8n 原始第一层输入为 3 通道：

```yaml
Conv: in_channels=3, out_channels=16, kernel=3, stride=2
```

修改为 4 通道：

```yaml
Conv: in_channels=4, out_channels=16, kernel=3, stride=2
```

参数增加极少。

原始第一层参数：

[
$$
3 \times 16 \times 3 \times 3 = 432
$$
]

修改后：

[
$$
4 \times 16 \times 3 \times 3 = 576
$$
]

只增加：

[
$$
576 - 432 = 144
$$
]

这个参数增加可以忽略。

------

## 4.7 EGI 的论文价值

EGI 可以支撑你的核心论点：

> 在伪色 X 射线安检图像中，颜色映射不稳定，材质颜色提示并不可靠；边缘结构比颜色信息更适合用于重叠场景下的违禁品检测。

------

## 4.8 EGI 消融设计

必须做以下对比：

| 输入形式                    | 目的             |
| --------------------------- | ---------------- |
| RGB                         | 原始基线         |
| Gray                        | 验证颜色是否必要 |
| RGB + HSV                   | 验证颜色空间增强 |
| RGB + Material Color Branch | 验证材质颜色分支 |
| RGB + Sobel                 | 边缘输入         |
| RGB + Scharr                | 推荐方案         |
| RGB + Learnable Edge        | 可学习边缘       |

你希望得到的结果是：

1. RGB + HSV 提升有限；
2. 材质颜色分支不稳定；
3. RGB + Scharr 对 AP-thin、AP-small、Hidden Recall 提升明显。

------

# 5. 模块 3：Modified Stem 输入适配层

## 5.1 模块名称

> **XR-Stem：X-ray Input Adaptation Stem**

中文：

> **X 射线输入适配层**

------

## 5.2 设计动机

YOLOv8n 默认只接受 3 通道 RGB 图像。加入 EGI 后，输入变成 4 通道，因此需要修改 Stem。

但不能简单地让第一层卷积承担全部融合任务。为了让边缘图和 RGB 信息更稳定融合，可以设计一个轻量输入适配层。

------

## 5.3 推荐结构

### 方案 A：最轻量版本

```text
Input: 4 × H × W
        ↓
Conv 3×3, stride=2, 4→16
        ↓
BN + SiLU
```

优点：

1. 最简单；
2. 几乎不增加参数；
3. 便于复现；
4. 适合 Lite 主模型。

推荐用于：

> YOLOv8n-XR-Lite

------

### 方案 B：边缘分支适配版本

```text
RGB: 3 × H × W         Edge: 1 × H × W
     ↓                      ↓
Conv 3×3                  Conv 3×3
3→12                      1→4
     ↓                      ↓
Concat: 16 channels
        ↓
BN + SiLU
```

优点：

1. RGB 和 Edge 初始特征分开提取；
2. 边缘图不会被 RGB 特征完全淹没；
3. 对小目标和细长目标可能更好。

缺点：

1. 结构略复杂；
2. 增加一点参数；
3. YAML 修改更多。

推荐用于：

> 消融实验或 Plus 版本。

------

### 方案 C：边缘门控适配版本

```text
RGB feature F_rgb
Edge feature F_e
        ↓
Gate = sigmoid(Conv(F_e))
        ↓
F_out = F_rgb × (1 + Gate)
```

数学表达：

[
$$
F_{out}=F_{rgb}\cdot (1+\sigma(\text{Conv}(F_e)))
$$
]

优点：

1. 边缘图作为门控增强 RGB 特征；
2. 更符合“边缘引导”的论文叙事。

缺点：

1. 稍复杂；
2. 需要更多消融证明。

建议：

> 不作为第一版主模型，后续可以作为改进点。

------

## 5.4 最终推荐

当前候选主线采用：

> **方案 A：4 通道直接输入 + 第一层卷积修改。**

理由：

1. 简单；
2. 轻量；
3. 参数增加极小；
4. 容易和 YOLOv8 框架兼容；
5. 适合作为候选主线的基础输入方案。

------

# 6. 模块 4：Backbone 骨干网络设计

## 6.1 基础 Backbone

以 YOLOv8n 的 Backbone 为基础：

```text
Input
 ↓
Conv
 ↓
C2f
 ↓
Conv
 ↓
C2f
 ↓
Conv
 ↓
C2f
 ↓
Conv
 ↓
C2f
 ↓

```

输出多尺度特征：

| 特征层 | 下采样倍数 | 语义             |
| ------ | ---------- | ---------------- |
| P3     | 1/8        | 小目标、细节     |
| P4     | 1/16       | 中等目标         |
| P5     | 1/32       | 大目标、全局语义 |

------

## 6.2 为什么不大改 Backbone

你不能把 Backbone 改得太重，否则会偏离“轻量实时”。

不建议：

1. 大规模 Transformer Backbone；
2. Swin Transformer 替换主干；
3. 大型 Mamba Backbone；
4. 重型双流网络；
5. 大量堆叠注意力模块。

建议策略：

> 保留 YOLOv8n Backbone 主体，只在关键尺度加入轻量模块。

------

## 6.3 Backbone 修改点

建议只做 3 处修改：

| 修改位置        | 模块      | 目的                 |
| --------------- | --------- | -------------------- |
| 输入层          | XR-Stem   | 接受 4 通道输入      |
| P3/P4/P5 输出后 | EMA-Lite  | 增强边缘和空间显著性 |
| SPPF 后         | AIFI-Lite | 增强全局上下文       |

# 7. 模块 5：EMA-Lite 边缘-空间注意力模块

## 7.1 模块名称

> **EMA-Lite：Edge-aware Multi-scale Attention Lite**

中文：

> **轻量边缘感知多尺度注意力模块**

------

## 7.2 设计动机

X 射线违禁品检测中，目标经常被遮挡或重叠。普通卷积容易把目标和背景混在一起。注意力模块可以帮助网络关注更有判别力的区域。

但不能直接使用很重的注意力模块，例如完整自注意力，因为会增加计算量。

EMA-Lite 的目标是：

> 用很小的计算代价增强目标边缘、局部显著区域和多尺度结构响应。

------

## 7.3 插入位置

推荐插入在：

| 位置            | 是否推荐           | 原因                   |
| --------------- | ------------------ | ---------------------- |
| P3 后           | 推荐，但要看 FLOPs | 有利于小目标和细长目标 |
| P4 后           | 强烈推荐           | 精度和速度平衡最好     |
| P5 后           | 推荐               | 有利于语义和遮挡上下文 |
| 每个 C2f 内部   | 不推荐             | 改动大，计算增加       |
| Neck 每次融合后 | 可选               | 需要消融证明           |

主模型建议：

> **P4 + P5 插入 EMA-Lite**

Plus 版本建议：

> **P3 + P4 + P5 插入 EMA-Lite**

------

## 7.4 EMA-Lite 输入输出

输入特征：

[
$$
F \in \mathbb{R}^{C \times H \times W}
$$
]

输出特征：

[
$$
F' \in \mathbb{R}^{C \times H \times W}
$$
]

保持通道数和空间尺寸不变，便于直接插入 YOLOv8。

------

## 7.5 EMA-Lite 结构设计

推荐结构如下：

```text
Input Feature F
        ↓
Group Split
        ↓
Depthwise 3×3 Conv
        ↓
Horizontal Pooling + Vertical Pooling
        ↓
1×1 Conv for Channel Compression
        ↓
Spatial Attention Map
        ↓
Channel Attention Map
        ↓
Sigmoid
        ↓
F' = F + F × Attention
```

------

## 7.6 数学表达

输入：

[
$$
F \in \mathbb{R}^{C \times H \times W}
$$
]

先进行分组：

[
$$
F = [F_1, F_2, ..., F_g]
$$
]

其中：

[
$$
F_i \in \mathbb{R}^{\frac{C}{g} \times H \times W}
$$
]

对每组特征做深度卷积：

[
$$
\hat{F_i} = DWConv_{3\times3}(F_i)
$$
]

提取水平和垂直方向上下文：

[
$$
z_h = AvgPool_h(\hat{F_i})
$$
]

[
$$
z_w = AvgPool_w(\hat{F_i})
$$
]

融合方向信息：

[
$$
A_i = \sigma(Conv_{1\times1}([z_h,z_w]))
$$
]

增强特征：

[
$$
F_i' = F_i \cdot A_i
$$
]

残差输出：

[
$$
F' = F + Concat(F_1',F_2',...,F_g')
$$
]

------

## 7.7 为什么用分组

分组的作用是降低计算量。

如果直接对全部通道做注意力，计算较高。分组后，每组通道数减少：

[
$$
C_i = \frac{C}{g}
$$
]

计算量显著下降。

建议：

| 特征层 | 通道数 | group   |
| ------ | ------ | ------- |
| P3     | 128    | 4       |
| P4     | 256    | 8       |
| P5     | 512    | 8 或 16 |

具体通道数要根据你的 YOLOv8n 配置确定。

------

## 7.8 EMA-Lite 预期作用

| 指标      | 预期变化 |
| --------- | -------- |
| mAP50     | 小幅提升 |
| mAP50:95  | 中等提升 |
| Recall    | 提升     |
| Hidden AP | 明显提升 |
| AP-thin   | 明显提升 |
| FPS       | 小幅下降 |
| Params    | 小幅增加 |

EMA-Lite 的重点不是让 Easy 样本大幅提升，而是：

> 提高遮挡、隐藏、边缘弱目标的召回。

------

# 8. 模块 6：AIFI-Lite 全局上下文模块

## 8.1 模块名称

> **AIFI-Lite：Attention-based Intra-scale Feature Interaction Lite**

中文：

> **轻量级尺度内全局特征交互模块**

------

## 8.2 设计动机

严重重叠 X 射线图像中，局部区域可能无法判断目标类别。例如：

1. 刀的一部分被遮挡；
2. 剪刀只露出一端；
3. 枪的局部结构与工具混淆；
4. 扳手与钳子局部形状相似；
5. 目标被背景金属物体干扰。

这时需要更强的全局上下文。

AIFI-Lite 的目标是：

> 在深层特征中建立全局关系，帮助模型根据整体结构和上下文判断被遮挡目标。

------

## 8.3 插入位置

推荐插入在：

```text
Backbone P5
    ↓
SPPF
    ↓
AIFI-Lite
    ↓
Neck
```

也就是：

> **SPPF 后、Neck 前。**

原因：

1. P5 分辨率低，计算成本小；
2. 语义信息强，适合全局建模；
3. 不会显著拖慢模型；
4. 对重叠场景有帮助。

------

## 8.4 输入输出

输入：

[
$$
F_5 \in \mathbb{R}^{C \times H \times W}
$$
]

输出：

[
$$
F_5' \in \mathbb{R}^{C \times H \times W}
$$
]

尺寸不变。

------

## 8.5 AIFI-Lite 结构

推荐结构：

```text
Input F
    ↓
1×1 Conv 降维
    ↓
DWConv 3×3 注入局部位置感知
    ↓
Lightweight Self-Attention
    ↓
1×1 Conv 升维
    ↓
Residual Add
    ↓
FFN-Lite
    ↓
Output
```

------

## 8.6 数学表达

降维：

[
$$
F_r = Conv_{1\times1}(F)
$$
]

其中：

[
$$
C_r = \frac{C}{r}
$$
]

建议：

[
$$
r = 2 \text{ or } 4
$$
]

生成 Q、K、V：

[
$$
Q = W_qF_r
$$
]

[
$$
K = W_kF_r
$$
]

[
$$
V = W_vF_r
$$
]

轻量自注意力：

[
$$
A = Softmax\left(\frac{QK^T}{\sqrt{d}}\right)
$$
]

[
$$
F_{attn}=AV
$$
]

升维：

[
$$
F_o = Conv_{1\times1}(F_{attn})
$$
]

残差：

[
$$
F' = F + F_o
$$
]

再经过轻量 FFN：

[
$$
F'' = F' + Conv_{1\times1}(DWConv(Conv_{1\times1}(F')))
$$
]

------

## 8.7 如何控制计算量

AIFI-Lite 必须轻量。

控制方式：

1. 只放在 P5；
2. 先降维；
3. 使用较少 attention heads；
4. 使用 DWConv 代替大卷积；
5. 不在 P3 上使用；
6. 不堆叠多个 Transformer block。

建议参数：

| 设置            | 推荐值    |
| --------------- | --------- |
| 插入位置        | SPPF 后   |
| 降维比例 r      | 2 或 4    |
| attention heads | 4         |
| FFN expansion   | 2         |
| dropout         | 0 或 0.05 |
| block 数量      | 1         |

------

## 8.8 AIFI-Lite 预期效果

| 指标               | 预期变化           |
| ------------------ | ------------------ |
| Easy AP            | 小幅提升或基本不变 |
| Hard AP            | 提升               |
| Hidden AP          | 明显提升           |
| Heavy Occlusion AP | 明显提升           |
| FLOPs              | 小幅增加           |
| FPS                | 小幅下降           |

AIFI-Lite 的价值主要体现在：

> **重叠、遮挡、隐藏目标。**

------

# 9. 模块 7：Neck 多尺度融合设计

## 9.1 基础 Neck

YOLOv8n 使用 PAN-FPN 风格的多尺度融合。

默认检测尺度：

| 检测层 | 下采样倍数 | 适合目标 |
| ------ | ---------- | -------- |
| P3     | 1/8        | 小目标   |
| P4     | 1/16       | 中目标   |
| P5     | 1/32       | 大目标   |

------

## 9.2 Neck 修改原则

不建议大幅重构 Neck。

建议：

1. 保留 YOLOv8n PAN-FPN 主体；
2. 在融合后加入轻量 EMA-Lite；
3. 不使用 BiFPN 大量堆叠；
4. 不使用复杂 Transformer Neck；
5. 可选增加 P2-Lite。

------

## 9.3 Neck 中 EMA-Lite 的插入方式

推荐两种方案。

### 方案 A：Backbone 输出后插入

```text
P3_backbone → EMA-Lite → P3_neck
P4_backbone → EMA-Lite → P4_neck
P5_backbone → EMA-Lite → P5_neck
```

优点：

1. 结构清晰；
2. 消融容易；
3. 不影响 Neck 主体。

推荐用于主模型。

------

### 方案 B：Neck 融合后插入

```text
FPN融合后的 P3 → EMA-Lite
FPN融合后的 P4 → EMA-Lite
FPN融合后的 P5 → EMA-Lite
```

优点：

1. 融合后特征更丰富；
2. 可能提升更明显。

缺点：

1. 计算量可能增加；
2. 需要更多消融。

建议作为对比实验。

------

## 9.4 最终推荐

主模型使用：

> **Backbone 输出 P4/P5 后插入 EMA-Lite，P3 是否加入由消融决定。**

Plus 版本使用：

> **P3/P4/P5 均加入 EMA-Lite。**

------

# 10. 模块 8：P2-Lite 小目标检测分支

## 10.1 模块名称

> **P2-Lite Detection Head**

中文：

> **轻量 P2 小目标检测分支**

------

## 10.2 设计动机

X 射线违禁品中有很多小目标和细长目标：

1. Bullet；
2. Knife tip；
3. Scissors tip；
4. Lighter；
5. Handcuff small parts；
6. Gun parts；
7. Wrench edge。

YOLOv8 默认 P3/P4/P5 检测头可能对很小目标不够敏感。

P2 的下采样倍数为 1/4，空间分辨率更高：

| 层   | 下采样 | 适合     |
| ---- | ------ | -------- |
| P2   | 1/4    | 很小目标 |
| P3   | 1/8    | 小目标   |
| P4   | 1/16   | 中目标   |
| P5   | 1/32   | 大目标   |

------

## 10.3 P2-Lite 结构

从 Backbone 浅层取 P2 特征：

```text
Backbone P2 feature
        ↓
Neck P3 upsample
        ↓
Concat(P2, upsampled P3)
        ↓
Light C2f / DWConv C2f
        ↓
P2 Detect Head
```

------

## 10.4 推荐轻量实现

### 方案 A：普通 P2 Head

```text
P2 + P3 + P4 + P5 Detect
```

优点：

1. AP-small 提升明显；
2. 实现简单。

缺点：

1. FLOPs 增加明显；
2. FPS 下降。

------

### 方案 B：P2-Lite + DWConv

```text
P2 Fusion
    ↓
Depthwise Conv
    ↓
Pointwise Conv
    ↓
Detect
```

优点：

1. 比普通 P2 更轻；
2. 保留小目标检测能力。

推荐用于 Plus 版。

------

### 方案 C：共享检测头

P2/P3 使用共享 head 参数：

```text
Detect Head P2 and P3 share partial parameters
```

优点：

1. 减少参数；
2. 适合轻量化。

缺点：

1. 实现复杂；
2. 需要修改 YOLO Detect 层。

不建议第一版做。

------

## 10.5 P2-Lite 是否进主模型

判断标准：

| 结果                                 | 决策             |
| ------------------------------------ | ---------------- |
| AP-small 提升 ≥ 3%，FPS 下降 < 10%   | 加入 Lite 主模型 |
| AP-small 提升 ≥ 3%，FPS 下降 10%–20% | 放入 Plus        |
| AP-small 提升 < 2%，FPS 下降明显     | 删除             |
| 只提升小目标但 Hidden AP 不变        | 作为补充模块     |

------

## 10.6 推荐结论

主论文建议：

> **YOLOv8n-XR-Lite 使用 P3/P4/P5 检测头。YOLOv8n-XR-Plus 额外加入 P2-Lite，用于小目标增强实验。**

这样更稳。

------

# 11. 模块 9：检测头设计

## 11.1 基础检测头

YOLOv8 使用解耦检测头，分别预测：

1. bbox；
2. class probability；
3. distribution focal regression。

YOLOv8 是 anchor-free 检测方式。

------

## 11.2 是否修改检测头

建议：

> **主模型不大改检测头。**

原因：

1. YOLOv8 检测头已经成熟；
2. 修改检测头会增加论文复杂度；
3. 你的创新点应集中在 X 射线特性建模；
4. 避免审稿人认为堆改动。

------

## 11.3 可做的小改动

可以做以下轻量修改：

| 修改                 | 是否推荐     | 说明         |
| -------------------- | ------------ | ------------ |
| 保持默认 Detect Head | 强烈推荐     | 主模型       |
| 加 P2 Head           | 可选         | Plus 版本    |
| 使用共享轻量 head    | 可选         | 减少参数     |
| 更换复杂 head        | 不推荐       | 影响可解释性 |
| 增加旋转框           | 不推荐第一版 | 标注不支持   |

------

## 11.4 细长目标是否需要旋转框

Knife、Scissors、Wrench 等是细长目标，但如果你的标签是水平 bbox，不建议第一版引入旋转框。

原因：

1. 需要旋转框标注；
2. 数据集不一定支持；
3. YOLOv8 原始框架需较大修改；
4. 论文工作量上升。

可以在未来工作中写：

> 后续将探索 oriented bounding box detection for elongated prohibited items.

# 12. 模块 10：损失函数设计

## 12.1 总体损失

建议总损失：

[
$$
L = \lambda_{box}L_{box}+\lambda_{cls}L_{cls}^{xr}+\lambda_{dfl}L_{dfl}
$$
]

其中：

| 项             | 作用               |
| -------------- | ------------------ |
| (L_{box})      | 边界框回归         |
| (L_{cls}^{xr}) | X-ray 场景分类损失 |
| (L_{dfl})      | 分布式框回归损失   |

------

## 12.2 框回归损失

建议第一版保持 YOLOv8 默认框损失。

可以使用：

[
$$
L_{box}=L_{CIoU}
$$
]

或 YOLOv8 框架默认实现。

不建议第一版同时改成 SIoU、EIoU、WIoU、MPDIoU 等。

原因：

1. 容易分散创新点；
2. 审稿人会认为你只是堆技巧；
3. 框损失提升未必稳定；
4. 消融量会变大。

------

## 12.3 分类损失改进

X 射线违禁品检测中更关心漏检，所以可以对分类损失做轻量改造。

基础分类损失：

[
$$
L_{cls}=L_{BCE}
$$
]

改为：

[
$$
L_{cls}^{xr}=w_c \cdot w_{occ} \cdot L_{BCE}
$$
]

其中：

- (w_c)：类别均衡权重；
- (w_{occ})：遮挡权重。

------

## 12.4 类别均衡权重

类别权重：

[
$$
w_c=\frac{1-\beta}{1-\beta^{n_c}}
$$
]

其中：

| 符号    | 含义                             |
| ------- | -------------------------------- |
| (n_c)   | 类别 (c) 的样本数量              |
| (\beta) | 平滑系数，一般取 0.999 或 0.9999 |

注意：

- SPXray 类别均衡，(w_c) 作用可能不明显；
- PIDray / SIXray 类别不均衡时更有用。

所以建议：

> 在 SPXray 上可以不启用类别均衡损失，在 PIDray 上启用并消融。

------

## 12.5 遮挡权重

如果没有人工遮挡标签，可以用 bbox 重叠程度近似遮挡强度。

对第 (i) 个目标，定义：

[
$$
o_i = \max_{j \neq i} IoU(b_i,b_j)
$$
]

或者定义为与其他 bbox 的最大交叠比例：

[
$$
o_i = \max_{j \neq i} \frac{Area(b_i \cap b_j)}{Area(b_i)}
$$
]

遮挡权重：

[
$$
w_{occ}=1+\lambda_{occ} \cdot o_i
$$
]

其中：

[
$$
\lambda_{occ} \in [0.5, 2.0]
$$
]

推荐初始值：

[
$$
\lambda_{occ}=1.0
$$
]

------

## 12.6 最终分类损失

[
$$
L_{cls}^{xr}=w_c \cdot (1+\lambda_{occ}o_i) \cdot L_{BCE}
$$
]

如果使用 Focal Loss：

[
$$
L_{cls}^{xr}=w_c \cdot w_{occ} \cdot L_{Focal}
$$
]

但建议第一版不要直接上 Focal Loss，先做消融。

------

## 12.7 损失函数最终推荐

主模型默认：

```text
YOLOv8 default box loss
YOLOv8 default DFL
BCE classification loss
+ optional occlusion-aware weight on PIDray / OPIXray
```

论文中可以把遮挡权重作为可选增强：

> **Occlusion-aware classification reweighting**

不要把损失函数作为最大创新点。

# 13. 推理后处理设计

## 13.1 默认 NMS

YOLOv8 默认使用 NMS。

对于多数情况保留默认 NMS 即可。

------

## 13.2 为什么考虑 Soft-NMS

X 射线图像中目标可能高度重叠。如果两个真实目标框重叠较大，普通 NMS 可能错误抑制其中一个。

所以可以作为可选后处理：

> **Occlusion-aware Soft-NMS**

------

## 13.3 Soft-NMS 公式

普通 NMS 直接删除高 IoU 框。

Soft-NMS 对得分进行衰减：

[
$$
s_i = s_i \cdot e^{-\frac{IoU(b_i,b_m)^2}{\sigma}}
$$
]

其中：

- (b_m)：当前最高分框；
- (b_i)：候选框；
- (\sigma)：衰减系数。

------

## 13.4 是否放进主模型

建议：

| 方案                  | 建议         |
| --------------------- | ------------ |
| 默认 NMS              | 主模型       |
| Soft-NMS              | 消融实验     |
| Weighted Boxes Fusion | 不建议主模型 |
| Learnable NMS         | 不建议       |

原因：

1. Soft-NMS 可能增加推理时间；
2. 部署时未必方便；
3. 主创新点应放在网络结构和训练策略上。

------

# 18. 每个模块对应的论文创新点

## 18.1 创新点 1：伪色归一化 + 边缘引导输入

对应模块：

1. PCN；
2. EGI；
3. XR-Stem。

核心表述：

> 提出一种面向伪色 X 射线图像的输入建模策略，不直接依赖不稳定的材质颜色，而是通过伪色归一化降低设备分布偏移，并引入边缘结构图增强违禁品轮廓表达。

支撑实验：

1. 输入形式消融；
2. 伪色扰动鲁棒性；
3. AP-thin；
4. AP-small。

------

## 18.2 创新点 2：轻量边缘-遮挡感知特征增强

对应模块：

1. EMA-Lite；
2. AIFI-Lite。

核心表述：

> 设计轻量边缘-空间注意力和深层全局上下文交互模块，在低计算开销下增强遮挡目标、细长目标和隐藏违禁品的判别特征。

支撑实验：

1. 注意力模块对比；
2. EMA 插入位置消融；
3. AIFI 全局上下文消融；
4. Hidden AP；
5. Heavy AP。

## 18.3 创新点 4：轻量实时检测框架

对应模块：

1. YOLOv8n 轻量底座；
2. 低开销 EMA-Lite；
3. 只在 P5 使用 AIFI-Lite；

支撑实验：

# 19. 不建议纳入主模型的内容

为了让论文更聚焦，以下内容不建议作为主模型核心。

## 19.1 不建议主打材质颜色分支

原因：

1. 你已经验证效果差；
2. 伪色颜色不稳定；
3. 多设备泛化差；
4. 严重重叠时颜色会混合；
5. 容易被审稿人质疑物理意义不充分。

可以作为负面消融：

> RGB + Material Color Branch

用于证明：

> 颜色材质提示不如边缘结构稳定。

------

## 19.2 不建议大规模 Transformer

原因：

1. 参数量和 FLOPs 增加；
2. 实时性下降；
3. 与 YOLOv8n 轻量目标冲突；
4. 需要大量数据支撑。

只保留：

> AIFI-Lite at P5

即可。

------

## 19.3 不建议同时改太多损失函数

原因：

1. 消融复杂；
2. 创新点分散；
3. 审稿人容易认为堆技巧；
4. 难解释哪个模块真正有效。

损失函数作为辅助即可。

------

## 19.4 不建议第一版做旋转框

原因：

1. 数据集标注未必支持；
2. 需要改检测头；
3. 增加实验负担；
4. 主线会偏离。

# 25. 当前候选模型体系清单

下面是当前最精简但完整的候选清单。XR-Nano 暂作为 SPXray 上的候选主线，最终主模型需等待 PIDray、OPIXray 等其他数据集验证后确定。

## 候选主线：YOLOv8n-XR-Nano

1. **输入端**
   - PCN 伪色归一化；
   - Scharr 边缘提取；
   - RGB + Edge 四通道输入。
2. **Stem**
   - 第一层 Conv 从 3 通道改为 4 通道；
   - 其他结构保持轻量。
3. **Backbone**
   - 保留 YOLOv8n C2f 主体；
   - 不大幅更换主干；
   - 不插入 EMA-Lite，EMA-Lite 仅作为 XR-Lite 消融模块。
4. **Context**
   - 不加入 AIFI-Lite，AIFI-Lite 仅作为 XR-Lite 消融模块；
   - 当前候选主线不额外引入 Transformer 类上下文模块。
5. **Neck**
   - 保留 YOLOv8n PAN-FPN；
   - 不使用重型 BiFPN 或 Transformer Neck。
6. **Head**
   - XR-Nano 使用 P3/P4/P5；
   - P2-Lite / XR-Plus 增加 P2 分支，仅作为小目标增强消融。
7. **Loss**
   - 保留 YOLOv8 默认框回归和 DFL；
   - 分类损失可加入遮挡权重；
   - 类别均衡权重在 PIDray/SIXray 上消融。
9. **Post-processing**
   - 默认 NMS；
   - Soft-NMS 仅作为消融。
10. **部署**

- PyTorch FP32；
- ONNX；
- TensorRT FP16；
- 可选 INT8。

# 27. XR-Plus-v2 / v3 / v4 增强候选计划

## 27.1 追加背景

当前 `YOLOv8n-XR-Plus` 已经定义为：

```text
XR-Plus = XR-Nano + EMA-Lite + AIFI-Lite + P2-Lite
```

其中 `XR-Nano = PCN + EGI`。在现有结构中，P2 分支较轻，P3 分支仍存在进一步增强空间。考虑到后续实验允许 `XR-Plus` 参数量提高到 `3.6M-4M`，因此在正式 Plus 基础上追加三个增强候选版本。

这三个版本不替代原始 `XR-Plus`，而是作为阶段5的结构增强候选与消融对象。

## 27.2 版本定义

| 版本 | 结构定义 | 设计目的 | 参数量目标 |
| --- | --- | --- | --- |
| XR-Plus | XR-Nano + EMA-Lite + AIFI-Lite + P2-Lite | 原始 Plus 基线 | 约 3.31M |
| XR-Plus-v2 | XR-Plus + 强化 P2 C2f 融合 | 提升 AP-small / Recall-small | 约 3.62M |
| XR-Plus-v3 | XR-Plus + 加宽 P3 + P3 C2fEMALite | 提升 P3 小目标与细长目标表达 | 约 3.50M |
| XR-Plus-v4 | XR-Plus-v2 + XR-Plus-v3 | 同时强化 P2 与 P3 | 约 3.85M |

## 27.3 XR-Plus-v2：强化 P2 分支

原始 Plus 的 P2 分支为：

```text
P3 upsample + P2 concat
-> DWConv
-> 1x1 Conv
-> Detect(P2)
```

v2 将 P2 融合改为：

```text
P3 upsample + P2 concat
-> C2f
-> Detect(P2)
```

预期作用：

- 增强 P2 高分辨率特征的局部结构表达；
- 提升 AP-small；
- 提升 Recall-small；
- 保持参数量低于 4M。

## 27.4 XR-Plus-v3：加宽 P3 并加入 EMA-Lite

P3 是小目标与中小目标之间的关键尺度。v3 将 P3 输出从普通 `C2f` 调整为更强的 `C2fEMALite`，并提高 P3 输出通道。

结构目标：

```text
P3 neck fusion
-> wider C2fEMALite
-> Detect(P3)
```

预期作用：

- 提升 AP-small；
- 提升 AP-thin；
- 改善 P2 分支对小目标的过度依赖；
- 验证 P3 attention 是否比单纯 P2 head 更稳定。

## 27.5 XR-Plus-v4：P2 + P3 组合增强

v4 同时包含：

```text
强化 P2 C2f 融合
加宽 P3 C2fEMALite
```

它是阶段5中最强的 Plus 候选版本，目标是在 `3.6M-4M` 参数预算内尽可能提升小目标和细长目标检测。

## 27.6 判定规则

| 现象 | 结论 |
| --- | --- |
| AP-small 明显提升，mAP50:95 和 AP-thin 稳定 | 可保留为 Plus 候选 |
| 仅 AP-small 提升，但 AP-thin 或 mAP50:95 明显下降 | 只作为消融证据 |
| v3 提升 AP-thin，但 AP-small 不变 | 可作为 P3 注意力消融 |
| v4 全项最优且参数量 < 4M | 可作为最终 XR-Plus 增强版 |
| FPS 或显存代价过高 | 不作为主模型，仅保留论文消融 |
