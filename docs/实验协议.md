# X 射线违禁品检测实验协议

本协议用于冻结阶段 0 的实验规则。后续所有训练、消融、公共验证和论文结果表均以本文为准，避免根据结果反向调整指标或数据处理方式。

## 1. 数据集版本与分工

| 数据集 | 作用 | 是否必须 | 备注 |
| --- | --- | --- | --- |
| SPXray | 第一阶段训练、主消融、类别均衡条件下验证模块有效性 | 必须 | 当前本地路径为 `datasets/SPXray` |
| PIDray | 公开主基准、Easy/Hard/Hidden 验证、长尾场景验证 | 必须 | 后续接入官方划分 |
| OPIXray | 遮挡专项验证、细长目标验证 | 必须 | 后续接入官方遮挡等级 |
| CLCXray | 重叠泛化验证 | 建议 | 时间充足时加入 |
| SIXray | 类别不平衡和大规模泛化验证 | 可选 | 不作为唯一主基准 |

## 2. 数据划分规则

1. 所有数据集优先使用官方 train/val/test 或官方 test subset。
2. SPXray 当前使用：
   - `images/train`, `labels/train`
   - `images/val`, `labels/val`
   - `images/test`, `labels/test`
3. 任何增强方法，包括 Mosaic、MixUp、Copy-Paste、BGM-XR、Mix-Paste-XR、BLT-Mix，只允许作用于训练集。
4. 验证集和测试集必须保持原始图像与原始标签，不允许离线增强后再作为 val/test 评估。
5. 若后续生成 `SPXray_BLT_Mix`，只能将其训练部分作为训练增强数据来源，不作为正式验证或测试集。

## 3. 指标定义

### 3.1 基础检测指标

所有实验至少报告：

| 指标 | 定义 |
| --- | --- |
| Precision | `TP / (TP + FP)` |
| Recall | `TP / (TP + FN)` |
| AP50 | IoU=0.50 时的 AP |
| AP75 | IoU=0.75 时的 AP |
| mAP50 | 所有类别 AP50 的平均值 |
| mAP50:95 | IoU=0.50:0.95 多阈值平均 AP |

主指标为 `mAP50:95`。`mAP50` 仅作为辅助指标。

### 3.2 小目标指标

目标面积使用相对 bbox 面积：

```text
area = w * h / (W * H)
```

YOLO 标签中的 `w`、`h` 已归一化，因此直接使用：

```text
area = w * h
```

固定划分：

| 类型 | 定义 |
| --- | --- |
| Small | `area < 0.01` |
| Medium | `0.01 <= area < 0.05` |
| Large | `area >= 0.05` |

报告：

| 指标 | 作用 |
| --- | --- |
| AP-small | 小目标 AP |
| AP-medium | 中目标 AP |
| AP-large | 大目标 AP |
| Recall-small | 小目标召回率 |

### 3.3 细长目标指标

细长程度使用 bbox 长宽比：

```text
r = max(w, h) / min(w, h)
```

固定定义：

```text
Thin object: r > 3
```

报告：

| 指标 | 作用 |
| --- | --- |
| AP-thin | 细长目标 AP |
| Recall-thin | 细长目标召回率 |

Knife、Scissors、Wrench、Bullet、Plier 只作为典型细长类别进行辅助分析，不作为 AP-thin 的定义依据。

### 3.4 遮挡与隐藏指标

| 数据集 | 指标定义 |
| --- | --- |
| PIDray | 使用官方 Easy / Hard / Hidden 测试子集，报告 Hidden AP 和 Hidden Recall |
| OPIXray | 使用官方遮挡等级，报告 Heavy Occlusion AP 和 Heavy Occlusion Recall |
| SPXray | 如无官方 hidden 标注，不命名为 Hidden AP；仅可使用 bbox 重叠代理指标，命名为 Overlap AP |

SPXray 的重叠代理指标定义为：

$$
overlap_ratio_i = max_j Area(b_i intersection b_j) / Area(b_i)
$$
固定划分：

| 指标 | 定义 |
| --- | --- |
| AP-overlap@0.3 | `overlap_ratio_i >= 0.3` 的目标 AP |
| AP-heavy-overlap@0.5 | `overlap_ratio_i >= 0.5` 的目标 AP |

## 4. 统一训练设置

| 项目 | 固定规则 |
| --- | --- |
| Input size | 默认 `640x640` |
| Epochs | SPXray 300；PIDray 300；OPIXray 300 |
| Batch size | 根据显存选取，但同一组对比必须一致 |
| Optimizer | SGD 或 AdamW，同一组对比必须一致 |
| Initial LR | SGD: 0.01；AdamW: 0.001 |
| LR schedule | Cosine decay |
| Warmup epochs | 3 |
| Weight decay | 0.0005 |
| Mosaic | 开启，最后 10-20 epoch 关闭 |
| MixUp | 默认关闭，仅在增强消融中启用 |
| Copy-Paste | 默认关闭，仅在增强消融中启用 |
| Random seed | 主要结果至少 3 个 seed |
| NMS IoU | 同一组对比固定为 0.6 或 0.7 |
| Confidence threshold | mAP 使用全阈值扫描；可视化默认 0.25 |

主要结果应报告 `mean ± std`。Pilot 阶段允许单 seed 先判断方向，但不能作为最终论文结论。

## 5. 轻量化与速度测试规则

| 项目 | 固定规则 |
| --- | --- |
| 输入尺寸 | `640x640` |
| Batch size | 1 |
| 预热 | 200 次 |
| 正式测试 | 1000 张图像 |
| 设备 | 固定同一块 GPU |
| 精度 | PyTorch FP32；ONNX FP32；TensorRT FP16 可选 |
| 统计方式 | 平均延迟 + FPS |

所有模型必须报告：

| 指标 | 说明 |
| --- | --- |
| Params(M) | 参数量 |
| FLOPs(G) | 计算量 |
| Model Size(MB) | 权重大小 |
| FPS | 每秒处理帧数 |
| Latency(ms) | 单图推理延迟 |
| GPU Memory(MB) | 推理显存 |

## 6. 阶段 0 验收标准

阶段 0 完成时必须具备：

1. 数据集配置已固定在 `configs/datasets/`。
2. SPXray 的 train/val/test 数量可复现统计。
3. 每类实例数、每类图像数可复现统计。
4. small/medium/large 和 thin 统计可复现。
5. bbox area 直方图和 aspect ratio 直方图可复现。
6. 指标定义、增强边界、训练设置已写入本文档。

## 7. 当前阶段 0 命令

SPXray 数据统计命令：

```powershell
python scripts/check_dataset_stats.py --data configs/datasets/SPXray.yaml --output runs/dataset_stats/SPXray
```

输出文件：

| 文件 | 内容 |
| --- | --- |
| `summary.json` | 数据集总体和各 split 汇总 |
| `split_summary.csv` | train/val/test 图像数、标签数、实例数、尺度和细长统计 |
| `class_distribution.csv` | 每类实例数和每类图像数 |
| `bbox_area_histogram.csv` | bbox 相对面积分布 |
| `aspect_ratio_histogram.csv` | bbox 长宽比分布 |
