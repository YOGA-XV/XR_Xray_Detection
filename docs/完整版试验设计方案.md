# 4. 模型体系设计

## 4.1 基础模型

主干选择：

> **YOLOv8n**

理由：

YOLOv8n 官方 COCO 检测模型规模约为 3.2M 参数、8.7B FLOPs，是轻量实时检测的合适底座；YOLOv8s 则为 11.2M 参数、28.6B FLOPs，精度更高但计算成本明显增加。([Hugging Face](https://huggingface.co/Ultralytics/YOLOv8?utm_source=chatgpt.com))

你的目标是：

> 让改进后的模型精度接近或超过 YOLOv8s，但参数量和 FLOPs 尽量接近 YOLOv8n。

------

## 4.2 推荐最终模型命名

建议模型命名为：

> **YOLOv8n-XR-Lite**

英文论文题目可以是：

> **YOLOv8n-XR-Lite: An Edge- and Occlusion-Aware Lightweight Detector for Prohibited Item Detection in Pseudo-color X-ray Security Images**

中文题目可以是：

> **面向伪色 X 射线安检图像的边缘与遮挡感知轻量化违禁品检测方法**

------

## 4.3 模型模块组成

最终方法建议包含 5个核心模块：

| 模块      | 名称                                  | 目的                     |
| --------- | ------------------------------------- | ------------------------ |
| PCN       | Pseudo-color Normalization            | 降低伪色映射差异         |
| EGI       | Edge-Guided Input                     | 引入结构边缘先验         |
| EMA-Lite  | Edge-aware Multi-scale Attention Lite | 增强局部显著结构         |
| AIFI-Lite | Lightweight Global Context Module     | 改善重叠场景全局语义理解 |
| P2-Lite   | Lightweight P2 Detection Head         | 提升小目标和细长目标检测 |

其中，**P2-Lite 当前不直接放入候选主线**，主要作为小目标增强消融。后续如果其他数据集证明它有稳定收益，再考虑形成两个版本：

| 版本            | 说明                              |
| --------------- | --------------------------------- |
| YOLOv8n-XR-Nano | 当前候选主线，PCN + EGI，强调轻量实时 |
| YOLOv8n-XR-Plus | 加 P2-Lite，作为小目标增强候选          |

# 5. 评价指标体系

## 5.1 基础检测指标

所有实验至少报告：

| 指标      | 公式/含义             | 作用               |
| --------- | --------------------- | ------------------ |
| Precision | (P=\frac{TP}{TP+FP})  | 衡量误报           |
| Recall    | (R=\frac{TP}{TP+FN})  | 衡量漏检           |
| F1-score  | (F1=\frac{2PR}{P+R})  | 综合精确率和召回率 |
| AP50      | IoU=0.50 时的 AP      | 宽松定位指标       |
| AP75      | IoU=0.75 时的 AP      | 严格定位指标       |
| mAP50     | 所有类别 AP50 平均    | 常规检测主指标     |
| mAP50:95  | IoU=0.50:0.95 平均 AP | 更严格综合指标     |

mAP50:95 必须保留，因为只报 mAP50 容易掩盖定位质量问题。Ultralytics 官方说明中也区分了 mAP50 与 mAP50-95，后者是在多个 IoU 阈值上平均，更能反映综合定位能力。([Hugging Face](https://huggingface.co/Ultralytics/YOLOv8?utm_source=chatgpt.com))

## 5.2 遮挡/隐藏场景指标

你的论文重点是重叠，所以必须额外报告：

| 指标                   | 说明                 |
| ---------------------- | -------------------- |
| Easy AP                | 简单样本 AP          |
| Hard AP                | 复杂背景/遮挡样本 AP |
| Hidden AP              | 隐藏违禁品 AP        |
| Hidden Recall          | 隐藏违禁品召回率     |
| Heavy Occlusion AP     | 重遮挡 AP            |
| Heavy Occlusion Recall | 重遮挡召回率         |

**PIDray 的 Hidden AP 使用官方 Hidden 测试子集；SPXray 如无官方 hidden 标签，不命名为 Hidden AP，而命名为 Overlap/Occlusion-proxy AP。**

定义提升量：

[
$$
\Delta AP_{hidden}=AP_{hidden}^{ours}-AP_{hidden}^{YOLOv8n}
$$
]

[
$$
\Delta R_{hidden}=R_{hidden}^{ours}-R_{hidden}^{YOLOv8n}
$$
]

如果你的总体 mAP50:95 只提升 1.5%，但 Hidden AP 提升 4%–6%，论文价值反而更高。

## 5.3 小目标指标

定义目标面积比例：

[
$$
area=\frac{w \times h}{W \times H}
$$
]

建议划分：

| 类型   | 定义                    |
| ------ | ----------------------- |
| Small  | (area < 0.01)           |
| Medium | (0.01 \leq area < 0.05) |
| Large  | (area \geq 0.05)        |

报告：

| 指标         | 作用         |
| ------------ | ------------ |
| AP-small     | 小目标 AP    |
| AP-medium    | 中目标 AP    |
| AP-large     | 大目标 AP    |
| Recall-small | 小目标召回率 |

------

## 5.4 细长目标指标

定义长宽比：

[
$$
r=\frac{\max(w,h)}{\min(w,h)}
$$
]

当：

[
$$
r>3
$$
]

认为是细长目标。

报告：

| 指标        | 作用           |
| ----------- | -------------- |
| AP-thin     | 细长目标 AP    |
| Recall-thin | 细长目标召回率 |

重点类别：

- Knife；
- Scissors；
- Wrench；
- Bullet；
- Plier。

mean \pm std

4. XR-Lite、P2-Lite、XR-Plus 未带来整体 mAP50:95 收益，作为结构增强或小目标增强消融证据保留。

## 8.3 输入形式消融

## 8.10 损失函数消融

建议总损失：

[
$$
L=\lambda_{box}L_{box}+\lambda_{cls}L_{cls}^{xr}+\lambda_{dfl}L_{dfl}
$$
]

类别均衡权重：

[
$$
w_c=\frac{1-\beta}{1-\beta^{n_c}}
$$
]

其中：

- (n_c)：类别 (c) 的样本数量；
- (\beta)：建议取 0.999 或 0.9999。

遮挡权重：

[
$$
w_{occ}=1+\lambda \cdot o_i
$$
]

最终分类损失：

[
$$
L_{cls}^{xr}=w_c \cdot w_{occ} \cdot L_{BCE/Focal}
$$
]

### Table 18. 损失函数消融实验（Loss function ablation）

| Loss Setting     | Box Loss | Cls Loss | DFL  | Class Balance | Occ Weight | mAP50:95 | Rare-class AP | Hidden Recall |
| ---------------- | -------- | -------- | ---- | ------------- | ---------- | -------- | ------------- | ------------- |
| YOLOv8 default   | CIoU/IoU | BCE      | ✓    | ×             | ×          |          |               |               |
| + Focal          | CIoU/IoU | Focal    | ✓    | ×             | ×          |          |               |               |
| + Varifocal      | CIoU/IoU | VFL      | ✓    | ×             | ×          |          |               |               |
| + Class-balanced | CIoU/IoU | CB-BCE   | ✓    | ✓             | ×          |          |               |               |
| + Occ-aware      | CIoU/IoU | CB-BCE   | ✓    | ✓             | ✓          |          |               |               |

因为 SPXray 类别均衡，所以类别均衡损失在 SPXray 上可能提升有限。它更适合在 PIDray 或 SIXray 上验证。

# 18. 最终结论

截至当前已完成的 SPXray 阶段实验，结论需要从“预期方案”修正为“实验事实”：

1. 输入侧增强方向成立：A1 PCN 将 AP-small 从 0.67436 提升到 0.69705；A2 EGI 将 mAP50:95 从 0.78790 提升到 0.79414；XR-Nano PCN+EGI 将 AP-thin 从 0.84901 提升到 0.86408。
2. XR-Nano PCN+EGI 是当前综合最稳的 YOLOv8n 改进版本，mAP50:95=0.79232、AP-small=0.69069、AP-thin=0.86408、AP-overlap@0.3=0.83156。
3. XR-Lite 没有超过 XR-Nano：mAP50:95=0.78465、AP-small=0.69026、AP-thin=0.85003，说明 EMA-Lite+AIFI-Lite 在当前设置下没有带来净收益。
4. XR-Plus 的 AP-small 最高，为 0.69893，但 mAP50:95 降至 0.77834、AP-thin 降至 0.83367，因此只能作为小目标增强的负代价消融，暂不适合作为最终主模型。
5. 三 seed 稳定性实验进一步支持 XR-Nano：mAP50:95=0.79832 ± 0.001、AP-small=0.69569 ± 0.001、AP-thin=0.86498 ± 0.002，均稳定高于 YOLOv8n。
6. 当前在 SPXray 上暂以 XR-Nano PCN+EGI 作为候选主线；XR-Lite、P2-Lite、XR-Plus 作为结构增强未取得综合收益的消融证据保留。最终主模型需等待 PIDray、OPIXray 等其他数据集验证后再确定。

把 SPXray 加入计划后，完整实验逻辑更清楚了：

> **SPXray 负责证明模型结构有效；PIDray 负责证明公开真实场景有效；OPIXray 负责证明遮挡场景有效；鲁棒性和速度实验负责证明论文主张完整成立。**

最终实验路线是：

```text
SPXray 类别统计
    ↓
YOLOv8n / YOLOv8s / YOLO11n 基线训练
    ↓
YOLOv8n-XR-Lite 模块消融
    ↓
SPXray 每类别、小目标、细长目标分析
    ↓
SPXray 预训练 → PIDray 微调
    ↓
PIDray Easy / Hard / Hidden 公开验证
    ↓
OPIXray 遮挡专项验证
    ↓
伪色扰动、遮挡扰动、跨数据集泛化
    ↓
速度、FLOPs、参数量、TensorRT 部署
    ↓
可视化与失败案例
```

这套实验设计可以支撑一篇结构完整、论证充分的论文。重点不是堆很多实验，而是让每个实验都对应一个清晰问题：

> **为什么你的方法适合伪色 X 射线安检图像？为什么它能改善重叠遮挡？为什么它仍然轻量实时？**
