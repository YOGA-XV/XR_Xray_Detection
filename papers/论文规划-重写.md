# 二、论文核心主张

你的论文应该围绕下面这句话展开：

> 本文提出一种面向伪色 X 射线安检图像的边缘与遮挡感知轻量检测框架，通过伪色归一化、边缘引导四通道输入和 X-ray 透射特性启发的遮挡增强，在保持轻量实时推理的同时，提高模型对小目标、细长目标、重叠目标和隐藏违禁品的检测鲁棒性。

这句话里面有三个层次：

| 层次                 | 解决的问题                             | 对应方法 |
| -------------------- | -------------------------------------- | -------- |
| 伪色不稳定           | 不同设备、不同伪色映射导致颜色分布偏移 | PCN      |
| 边缘弱、细长目标难检 | X-ray 图像纹理少，目标边界不明显       | EGI      |
| 遮挡和重叠严重       | 违禁品被其他物体遮挡、隐藏             | BLT-Mix  |

# 三、最终方法框架

建议最终主方法定义为：

```text
EOA-YOLO = YOLOv8n + PCN + EGI + BLT-Mix
```

其中：

```text
PCN：Pseudo-color Normalization，伪色归一化
EGI：Edge-Guided Input，边缘引导输入
BLT-Mix：基于 X-ray 透射特性的遮挡增强
```

推理阶段的主流程：

```text
Pseudo-color X-ray Image
        ↓
PCN
        ↓
Scharr Edge Extraction
        ↓
RGB + Edge 4-channel Input
        ↓
YOLOv8n Detector
        ↓
Detection Results
```

训练阶段额外加入：

```text
BLT-Mix Occlusion-aware Augmentation
```

需要强调：

```text
BLT-Mix 只用于训练，不增加推理开销
PCN + EGI 增加的推理成本很低
主干仍然保持 YOLOv8n 级别的轻量化
```

# 四、论文贡献点

建议贡献点写三条，不要太多。

## Contribution 1：边缘引导的 X-ray 输入表征

你提出一种面向伪色 X-ray 图像的输入表征方式：

```text
PCN + Scharr Edge + RGB-Edge 4-channel input
```

它的目标不是“让模型看到更多颜色”，而是让模型减少对不稳定伪色的依赖，增强对结构边缘、轮廓和细长目标的感知。

可以写成：

> We propose a pseudo-color normalized edge-guided input representation for X-ray prohibited item detection, which enhances structural cues while reducing reliance on unstable pseudo-color mappings.

------

## Contribution 2：X-ray 透射启发的遮挡增强

BLT-Mix 是你论文里最有潜力提高质量的模块。

普通 Copy-Paste 是把目标直接贴到背景上，视觉上更像自然图像操作；而 X-ray 图像中的遮挡是透射叠加，目标之间存在半透明、重叠、颜色混合和边界削弱。

所以 BLT-Mix 应该被定义为：

> 一种面向 X-ray 透射成像特性的局部遮挡样本合成策略。

可以写成：

> We design BLT-Mix, an X-ray-oriented occlusion augmentation strategy that simulates local transmittance-like object overlap while preserving high-risk pseudo-color cues.

------

## Contribution 3：面向难例的系统性评估

你不能只报总体 mAP。

必须重点评估：

```text
Small objects
Thin objects
Overlapped objects
Hidden items
Heavy occlusion
Pseudo-color perturbation
Synthetic occlusion perturbation
```

这能让论文从“模型小改进”变成“针对 X-ray 检测难点的系统性研究”。

可以写成：

> Extensive experiments on SPXray, PIDray, and OPIXray demonstrate that the proposed method improves detection robustness on small, thin, hidden, and heavily occluded prohibited items while maintaining lightweight inference.

## Abstract

摘要建议按照 5 句写。

### 第 1 句：问题

X-ray 安检图像中，违禁品常出现遮挡、重叠、小尺度、细长形态和伪色不稳定问题，导致通用检测器容易漏检。

### 第 2 句：现有方法不足

现有通用检测方法主要依赖 RGB 表观特征和自然图像增强策略，难以充分利用 X-ray 图像的结构边缘和透射成像特性。

在 SPXray、PIDray 和 OPIXray 上进行系统实验，并从小目标、细长目标、隐藏目标、重遮挡目标和鲁棒性扰动等角度进行评估。

### 第 5 句：结论

实验结果表明，该方法在保持轻量实时推理的同时，提高了复杂 X-ray 安检场景下的检测鲁棒性。

```text
4. YOLOv8n detector
```

重点说明：

```text
BLT-Mix is used only during training.
During inference, the model only requires PCN and edge extraction before detection.
```

### 3.2 Pseudo-color Normalized Edge-Guided Input

放 **Fig. 3 PCN + EGI 可视化**。

这一节讲清楚：

1. 为什么伪色不稳定；
2. PCN 如何减少分布偏移；
3. 为什么边缘结构重要；
4. 为什么选 Scharr；
5. 四通道输入如何进入 YOLOv8n；
6. 预训练权重如何适配四通道输入。

建议公式结构：

```text
I_rgb = original pseudo-color X-ray image

I_pcn = PCN(I_rgb)

E = Scharr(I_pcn)

I_4ch = Concat(I_pcn, E)
```

然后：

```text
Y = Detector(I_4ch)
```

### 3.3 BLT-Mix Occlusion-aware Augmentation

放 **Fig. 4 BLT-Mix 示意图**。

这一节讲：

1. 普通 Copy-Paste 的问题；
2. X-ray 遮挡更接近透射叠加；
3. BLT-Mix 的局部混合策略；
4. hue_proxy 的作用；
5. overlap sampling 的作用；
6. 训练阶段使用，不增加推理成本。

建议公式可以写成近似形式：

```text
I_mix = T_local(I_bg, I_patch, α)
```

其中：

```text
I_bg：背景图
I_patch：违禁品 patch
α：局部混合强度
T_local：局部透射式混合函数
```

不要把物理公式写得过重。你不是做严格 X-ray 物理仿真，而是做**物理启发增强**。表达要克制。

```text
Backbone: YOLOv8n backbone

Head: decoupled detection head
Input: RGB + Edge four-channel tensor
Loss: classification loss + localization loss + distribution focal loss
```

如果 EMA-Lite、AIFI-Lite、P2-Lite 最终结果不好，不要放进主方法。

它们可以放到消融：

```text
We also investigate several structural variants, including EMA-Lite, AIFI-Lite and P2-Lite, but use the simplest and most effective configuration as the final model.
```

## 5 Discussion

这节建议加。

高质量论文不应该只报结果，也应该讨论方法边界。

可以写三点：

### 5.1 Why edge guidance works for X-ray images

解释：

```text
X-ray 图像纹理弱
颜色映射不稳定
边缘和形状对违禁品更重要
```

### 5.2 Why BLT-Mix helps occlusion detection

解释：

```text
真实安检包裹中物体经常重叠
普通增强不能模拟半透明遮挡
BLT-Mix 提供了更多困难遮挡样本
```

### 5.3 Limitations

必须写。

例如：

```text
1. 极端遮挡下仍可能漏检；
2. Edge map 对严重噪声可能敏感；
3. BLT-Mix 是物理启发近似，不是严格 X-ray 成像仿真；
4. 对不同设备域迁移仍需进一步验证。
```

这会让论文显得更成熟。

```text
In this paper, we proposed EOA-YOLO, an edge- and occlusion-aware lightweight detection framework for prohibited item detection in pseudo-color X-ray security images. ```text
```

```text
PCN + EGI 3 seeds 后不稳定
BLT-Mix 不如 Copy-Paste
PIDray Hidden 没有收益
OPIXray Heavy 没有收益
总体 mAP 和难例指标都没有优势
```

如果只是总体 mAP 小幅提升，但难例没有提升，这篇论文会比较弱。
