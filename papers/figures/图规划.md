# Fig. 1 Overall Framework of EOA-YOLO

## 图名

**Overall Framework of the Proposed EOA-YOLO**

## 核心作用

这张图是整篇论文最重要的总览图。审稿人看完 Fig. 1 后，应该立刻明白：

1. 你的方法分为训练阶段和推理阶段；
2. BLT-Mix 只在训练阶段使用；
3. PCN + EGI 负责构造 RGB + Edge 四通道输入；
4. 检测器主体仍是轻量 YOLOv8n；
5. 你的方法不是简单堆模块，而是围绕 X-ray 图像特性设计。

------

## 推荐整体布局

建议采用**上下双分支结构**：

```text
(a) Training Stage

Input X-ray Image
        ↓
BLT-Mix Occlusion Augmentation
        ↓
PCN
        ↓
Scharr Edge Extraction
        ↓
RGB + Edge 4-channel Input
        ↓
YOLOv8n Detector
        ↓
Detection Loss


(b) Inference Stage

Input X-ray Image
        ↓
PCN
        ↓
Scharr Edge Extraction
        ↓
RGB + Edge 4-channel Input
        ↓
YOLOv8n Detector
        ↓
Detection Results
```

训练阶段放上方，推理阶段放下方。中间可以用虚线框强调：

```text
BLT-Mix is used only during training.
```

------

## 具体元素设计

### 左侧输入区

放一张真实 X-ray 图像缩略图，标注：

```text
Pseudo-color X-ray Image
```

图像旁边可以放一个小标签：

```text
RGB
```

### BLT-Mix 模块

只放在训练阶段，建议用浅色虚线边框包住，标注：

```text
BLT-Mix
Occlusion-aware Augmentation
Training only
```

模块内部可以画得简单一点：

```text
Background Image + Prohibited Item Patch → Mixed Occluded Sample
```

不要在 Fig. 1 里展开 BLT-Mix 公式，因为 Fig. 4 会专门讲。

### PCN 模块

标注：

```text
PCN
Pseudo-color Normalization
```

可以在模块前后各放一张小图：

```text
Original pseudo-color image → PCN-normalized image
```

### EGI 模块

标注：

```text
EGI
Scharr Edge Extraction
```

输出一个黑白边缘图，标注：

```text
Edge Map
```

### 四通道输入模块

这是 Fig. 1 的重点之一。

建议画成四层叠片：

```text
R
G
B
E
```

旁边标注：

```text
RGB + Edge
4-channel Input
```

这样审稿人能直观看出你不是普通三通道输入。

### Detector 模块

标注：

```text
YOLOv8n Detector
Backbone + Neck + Head
```

内部不用画太细，最多拆成三个小块：

```text
Backbone → PAN-FPN Neck → Detection Head
```

不要把 EMA-Lite、AIFI-Lite、P2-Lite 画进主图，除非后续实验确认它们是最终方法。

### 输出模块

训练阶段输出：

```text
Box Loss
Cls Loss
DFL Loss
```

推理阶段输出：

```text
Bounding Boxes
Class Labels
Confidence Scores
```

------

## 视觉重点

你要让这张图传达一个核心信息：

```text
Training: BLT-Mix + PCN + EGI + Detector
Inference: PCN + EGI + Detector
```

可以在图右上角加一个小注释：

```text
No BLT-Mix during inference
```

------

## 建议图注

```text
Fig. 1. Overall framework of the proposed EOA-YOLO. During training, BLT-Mix is used to synthesize X-ray-like occluded samples. Both training and inference employ pseudo-color normalization and Scharr-based edge guidance to construct a four-channel RGB-Edge input for the lightweight YOLOv8n detector. BLT-Mix is removed during inference and introduces no additional inference cost.
```

------

## 常见错误

不要犯这几个错误：

1. 不要把图画成普通 YOLO 结构图；
2. 不要把所有模块都堆进去；
3. 不要让 BLT-Mix 看起来推理阶段也在用；
4. 不要把四通道输入画得不明显；
5. 不要让图中文字太多。

# Fig. 2 Motivation Examples in X-ray Security Images

## 图名

**Motivation Examples of Challenging X-ray Security Images**

## 核心作用

这张图服务于 Introduction，用来证明你的研究问题真实存在。

审稿人看到这张图后应该认同：

```text
X-ray 安检图像确实存在伪色不稳定、边界弱、重叠遮挡、小目标和细长目标难检测的问题。
```

------

## 推荐整体布局

建议做成 **2 行 × 3 列**，共 6 个典型样本。

```text
(a) Pseudo-color ambiguity
(b) Weak boundary
(c) Heavy overlap
(d) Hidden prohibited item
(e) Small object
(f) Thin object
```

每个子图展示一张真实 X-ray 图像，并用目标框标出违禁品区域。

------

## 每个子图应该怎么选

### Fig. 2(a) Pseudo-color ambiguity

选择一个颜色容易误导模型的样本。

特点：

1. 违禁品和普通物品颜色接近；
2. 或者同一类物品在不同图像中呈现不同伪色；
3. 或者背景中有大面积颜色块干扰。

图上标注：

```text
Pseudo-color ambiguity
```

可以用箭头指向颜色相似区域，标注：

```text
Unstable color cue
```

------

### Fig. 2(b) Weak boundary

选择边界模糊的样本。

特点：

1. 违禁品轮廓不清晰；
2. 与背景物体重叠；
3. RGB 图像中边界很弱，但边缘图中可能更明显。

图上标注：

```text
Weak boundary
```

箭头标注：

```text
Faint object contour
```

------

### Fig. 2(c) Heavy overlap

选择多个物体严重重叠的图。

特点：

1. 违禁品被衣物、电子产品、杂物覆盖；
2. 目标只露出一部分；
3. 常规检测器容易漏检或框不准。

标注：

```text
Heavy overlap
```

箭头：

```text
Overlapped region
```

------

### Fig. 2(d) Hidden prohibited item

选择隐藏违禁品样本。

特点：

1. 目标被故意藏在其他物品中；
2. 可见区域小；
3. 形状不完整。

标注：

```text
Hidden item
```

箭头：

```text
Partially visible threat
```

------

### Fig. 2(e) Small object

选择小目标。

特点：

1. 目标占整张图比例很小；
2. 框非常小；
3. 容易被缩放、下采样或 NMS 影响。

标注：

```text
Small object
```

可以加一个局部放大框：

```text
Zoom-in
```

这个子图最好做一个 inset 小窗口，把小目标放大。

------

### Fig. 2(f) Thin object

选择刀、剪刀、细长金属物等。

特点：

1. 长宽比很大；
2. 面积不一定小，但细长；
3. 定位容易偏移。

标注：

```text
Thin object
```

箭头：

```text
Large aspect ratio
```

------

## 是否放检测结果

Fig. 2 可以只放原图和 GT，也可以放 YOLOv8n 的失败结果。

如果版面允许，我建议每个子图右下角加一个小的失败标记：

```text
Missed by YOLOv8n
```

或者：

```text
False positive
```

但不要把 Fig. 2 做成完整方法对比图，因为 Fig. 5 会负责检测对比。

------

## 建议图注

```text
Fig. 2. Representative challenging cases in X-ray security images. Pseudo-color ambiguity, weak object boundaries, heavy overlap, hidden prohibited items, small objects, and thin objects make prohibited item detection difficult for generic RGB-based detectors.
```

------

## 常见错误

1. 不要选太干净的样本；
2. 不要每个子图都展示同一种困难；
3. 不要把目标框画得太粗；
4. 不要让文字遮住目标；
5. 小目标样本必须加局部放大，否则审稿人看不清。

1. 小目标；

```text
Original
```

```text
PCN
```

# Fig. 4 Illustration of BLT-Mix

## 图名

**Illustration of the Proposed BLT-Mix Occlusion Augmentation**

## 核心作用

这张图解释你的第二个核心贡献：**BLT-Mix**。

审稿人看完应该明白：

1. 普通 Copy-Paste 不符合 X-ray 透射成像；
2. BLT-Mix 不是简单贴图；
3. BLT-Mix 模拟局部半透明重叠；
4. BLT-Mix 可以生成更合理的遮挡训练样本。

------

## 推荐整体布局

建议做成上下两行对比。

```text
(a) Conventional Copy-Paste

Background Image + Object Patch → Copy-Paste Result


(b) Proposed BLT-Mix

Background Image + Object Patch
        ↓
Local transmittance-like blending
        ↓
Hue proxy preservation
        ↓
BLT-Mix Result
```

------

## 具体布局方案

做成 2 行 × 4 列：

| Background | Object Patch | Composition Rule | Result             |
| ---------- | ------------ | ---------------- | ------------------ |
| Copy-Paste | Patch        | Direct paste     | Abrupt boundary    |
| Background | Patch        | BLT-Mix          | X-ray-like overlap |

第一行展示 Copy-Paste。

第二行展示 BLT-Mix。

------

## 第一行：Copy-Paste

### Background

选择一张没有该违禁品的 X-ray 背景图。

### Object Patch

裁出一个违禁品 patch，例如刀、剪刀、枪部件。

### Composition Rule

画一个简单操作箭头：

```text
Direct overwrite
```

或者：

```text
I_mix = Paste(I_patch, I_bg)
```

### Result

展示 Copy-Paste 后结果。

图上标注：

```text
Abrupt boundary
Unrealistic overlap
```

箭头指向贴图边界。

------

## 第二行：BLT-Mix

### Background

同一张背景图。

### Object Patch

同一个 patch。

### Composition Rule

画成三个小模块：

```text
Local blending
        ↓
Transmittance-like composition
        ↓
Hue proxy preservation
```

也可以加简化公式：

```text
I_mix = T_local(I_bg, I_patch, α)
```

但公式不要太复杂。

### Result

展示 BLT-Mix 后结果。

标注：

```text
Smooth overlap
X-ray-like occlusion
Preserved high-risk hue
```

------

## 图中必须强调

在 BLT-Mix 结果旁边加一个小标签：

```text
Training only
```

表示这是数据增强，不是推理模块。

------

## 选图建议

最好选一个贴图前后差异明显的样本：

1. Copy-Paste 边界突兀；
2. BLT-Mix 更像真实 X-ray 重叠；
3. 目标仍能看见，但被部分遮挡；
4. 伪色没有完全丢失。

------

## 建议图注

```text
Fig. 4. Illustration of BLT-Mix. Unlike conventional Copy-Paste, which directly overwrites local image regions and often produces abrupt boundaries, BLT-Mix synthesizes X-ray-like occlusion by local transmittance-inspired blending and high-risk hue preservation. BLT-Mix is used only during training.
```

------

## 常见错误

1. 不要让 BLT-Mix 结果看起来目标完全消失；
2. 不要让 Copy-Paste 和 BLT-Mix 区别不明显；
3. 不要写过重的物理公式；
4. 不要声称 BLT-Mix 是严格 X-ray 成像仿真；
5. 不要用自然图像例子，必须用 X-ray 图像。

------

# Fig. 6 Performance on Difficult Cases

## 图名

**Performance Comparison on Difficult Cases**

它是支撑论文主张的核心图之一。

------

## 推荐图形类型

建议使用**分组柱状图**。

横轴是难例类型：

```text
Small
Thin
Overlap
Hidden
Heavy Occlusion
```

纵轴是 AP 或 Recall。

每个难例类型下有 3 根柱：

```text

PCN + EGI
EOA-YOLO
```

## 推荐指标

不同难例对应不同指标：

| 难例            | 指标       |
| --------------- | ---------- |
| Small           | AP-small   |
| Thin            | AP-thin    |
| Overlap         | AP-overlap |
| Hidden          | AP-hidden  |

如果你不想混用指标，可以统一用：

```text
AP on subset
```

即对每个难例子集分别计算 mAP50:95。

------

## 推荐布局

可以做成一个主图：

```text
x-axis: Difficult subsets
y-axis: AP50:95
legend: YOLOv8n / PCN+EGI / EOA-YOLO
```

也可以拆成两个子图：

```text
(a) AP on object-shape subsets: Small / Thin
(b) AP on occlusion subsets: Overlap / Hidden / Heavy
```

1. 在每组柱子上方标出提升值：

```text
+2.1
+3.4
+5.2
```

1. 如果有 3 seeds，画误差线：

```text
mean ± std
```

1. 图例放在上方或右上角。

## 你希望这张图呈现的趋势

理想趋势是：

```text
YOLOv8n < PCN+EGI < EOA-YOLO
```

特别是在：

```text
Hidden
Heavy Occlusion
Small
Thin
```

这些难例上 EOA-YOLO 提升更明显。

------

## 建议图注

```text
Fig. 6. Performance comparison on difficult cases. The proposed EOA-YOLO shows larger gains on small, thin, hidden, and heavily occluded objects, indicating improved robustness in challenging X-ray security scenarios.
```

------

## 常见错误

## 推荐图形类型

# Fig. 9 Grad-CAM / Attention Visualization

## 图名

**Grad-CAM Visualization of Attention Regions**

或者：

**Class Activation Visualization on Challenging X-ray Images**

## 核心作用

这张图用可解释性结果说明模型为什么更有效。

它要支撑这个结论：

```text
相比 YOLOv8n，你的方法更关注目标轮廓、遮挡区域和结构性边缘，而不是背景伪色块。
```

------

## 推荐整体布局

建议做成 **4 行 × 4 列**。

每一行一个样本，每一列一个方法或视图：

| Original Image | YOLOv8n | PCN + EGI | EOA-YOLO |
| -------------- | ------- | --------- | -------- |
|                |         |           |          |

每个方法列展示 Grad-CAM 热力图叠加结果。

------

## 每行样本选择

### Row 1：Thin object

例如刀、剪刀。

你希望看到：

```text
YOLOv8n attention scattered
PCN+EGI focuses on contour
EOA-YOLO focuses on full thin structure
```

------

### Row 2：Small object

小违禁品。

你希望看到：

```text
YOLOv8n attention goes to background
EOA-YOLO focuses on small target region
```

------

### Row 3：Hidden object

隐藏目标。

你希望看到：

```text
EOA-YOLO activates around partially visible threat region
```

------

### Row 4：Heavy overlap

多物体重叠。

你希望看到：

```text
EOA-YOLO focuses on occluded prohibited item rather than surrounding clutter
```

------

## 每列具体内容

### 第 1 列：Original Image

放原图和 GT 框。

标注：

```text
Original
```

### 第 2 列：YOLOv8n Grad-CAM

标注：

```text
YOLOv8n
```

如果注意力分散，可以用箭头标注：

```text
Background distraction
```

### 第 3 列：PCN + EGI Grad-CAM

标注：

```text
PCN + EGI
```

如果注意力贴近边缘，标注：

```text
Boundary-focused activation
```

### 第 4 列：EOA-YOLO Grad-CAM

标注：

```text
EOA-YOLO
```

如果注意力集中在遮挡目标区域，标注：

```text
Occluded target region
```

------

## 热力图样式

建议：

1. 原图透明度 60%–70%；
2. 热力图透明度 30%–40%；
3. 不要遮住检测框；
4. 所有方法使用相同的 Grad-CAM 层；
5. 所有热力图使用相同归一化方式；
6. 不要手工调每张图的颜色强度，否则不公平。

------

## 选择哪一层做 Grad-CAM

建议选择检测器 backbone/neck 中较高层但仍保留空间信息的层，例如：

```text
Last C2f block before SPPF
```

或者：

```text
Neck feature layer before detection head
```

原则：

1. 太浅层：只看低级纹理，语义弱；
2. 太深层：空间分辨率太低；
3. 应统一所有模型取对应位置的特征层。

------

## 图中应避免的情况

如果出现以下情况，不要把 Fig. 9 放正文：

1. EOA-YOLO 热力图比 YOLOv8n 更分散；
2. 热力图主要关注背景；
3. 不同方法看起来几乎一样；
4. Grad-CAM 结果无法解释检测改进；
5. 只挑一个样本好看，其他样本不稳定。

如果效果一般，可以改成附录图。

------

## 建议图注

```text
Fig. 9. Grad-CAM visualization on challenging X-ray images. Compared with YOLOv8n, the proposed EOA-YOLO produces more concentrated activations around object contours, small prohibited items, and occluded target regions, suggesting that edge-guided input and occlusion-aware augmentation help the detector focus on structurally informative areas.
```

------

## 常见错误

1. 不要用不同层的 Grad-CAM 比较不同模型；
2. 不要对不同方法使用不同热力图归一化；
3. 不要只展示热力图，不展示原图；
4. 不要让热力图盖住目标框；
5. 不要把 Grad-CAM 当成严格证明，它只能作为辅助解释。
