# 三、建议的三大创新点

## 创新点 1：PCN + EGI，作为主方法核心

这是当前最稳的贡献。

你现在的模型设计是：伪色 X 射线图像经过 PCN，再通过 Scharr 提取边缘，形成 RGB + Edge 四通道输入；文档中的结构图也明确写了 PCN、EGI、四通道输入和 YOLOv8n 主干的流程。([GitHub](https://github.com/YOGA-XV/XR_Xray_Detection/blob/main/docs/模型体系设计方案.md))

建议命名：

> **Pseudo-color Normalized Edge Guidance，PNEG**

或者更简单：

> **X-ray Edge-Guided Input，XEGI**

论文里不要分散写 PCN 和 EGI，而是把它们组合成一个完整输入表征模块。因为单独看 PCN 或 EGI都不够“像论文创新”，但组合起来可以形成一个针对伪色 X-ray 的输入表征设计。

这一部分要证明：

1. 伪色 RGB 不是稳定材料语义；
2. 结构边缘比颜色更稳定；
3. RGB + Scharr Edge 比 RGB、Gray、HSV、Sobel、Canny 更适合当前任务；
4. 对 small、thin、overlap/hidden 场景更有效。

## 创新点 2：BLT-Mix，作为高质量论文的加分点

BLT-Mix 是你项目里最有潜力升级论文质量的部分。

你的 BLT-Mix 文档已经定义了训练阶段流程：先做基础几何增强，再做透射率乘性叠加与 hue_proxy 融合，然后进入 PCN、EGI 和 RGB+Edge 四通道检测流程；参数建议包括 BLT-Mix 概率 0.2–0.4、Patch 数 1–3、α 范围 0.4–1.0、Overlap IoU 0.1–0.7 等。([GitHub](https://github.com/YOGA-XV/XR_Xray_Detection/blob/main/docs/BLT-MIX.md))

它的价值在于：普通 Copy-Paste / MixUp 更像自然图像增强，而 X 射线图像是透射成像，重叠不是简单贴图。BLT-Mix 可以被包装成：

> **基于 X 射线透射成像特性的遮挡样本合成策略。**

但注意：BLT-Mix 现在还不能直接写成贡献，必须先跑出结果。你已经规划了增强对比，包括 Baseline、Linear MixUp、Copy-Paste、Mix-Paste、BGM、BLT-Mix 和 BLT-Mix + EGI；还规划了 Local BLT、α、hue_proxy、Overlap Sampling 的组件消融。这个设计是合理的，应该作为论文核心实验之一。([GitHub](https://github.com/YOGA-XV/XR_Xray_Detection/blob/main/docs/BLT-MIX.md))

## 创新点 3：面向难例的系统性评估协议

高质量论文不只靠模型，还靠实验设计。

你的项目文档已经规划了 SPXray、PIDray、OPIXray 的三阶段验证：先在 SPXray 做结构消融，再做 SPXray 到 PIDray 的领域预训练/微调，最后在 PIDray 和 OPIXray 上验证公开基准表现。([GitHub](https://github.com/YOGA-XV/XR_Xray_Detection/blob/main/docs/完整版试验设计方案.md))

这条路线是对的。PIDray 是真实场景违禁品检测大规模基准，强调类内差异、类别不平衡和遮挡，尤其包含 deliberately hidden items；OPIXray 则专门面向遮挡违禁品检测，并划分遮挡等级，适合验证你的方法是否真的对遮挡有效。([arXiv](https://arxiv.org/abs/2211.10763?utm_source=chatgpt.com))

你应该把实验重点从“整体 mAP 提升一点点”转向：

> **在 Hidden / Heavy Occlusion / Small / Thin 场景下，是否有稳定收益。**

这比单纯刷 mAP50:95 更像高质量论文。

# 四、最终方法框架

建议最终方法叫：

> **EOA-YOLO: Edge- and Occlusion-Aware YOLO for X-ray Prohibited Item Detection**

或者：

> **XEdge-YOLO: Edge-Guided Lightweight Detector for Pseudo-color X-ray Security Images**

我更推荐 **EOA-YOLO**，因为它能同时覆盖边缘和遮挡两个核心问题。

最终主模型建议定义为：

```text
Pseudo-color X-ray Image
        ↓
PCN: Pseudo-color Normalization
        ↓
EGI: Scharr Edge Guidance
        ↓
RGB + Edge 4-channel Input
        ↓
YOLOv8n detector
        ↓
Detection Results
```

训练阶段可加入：

```text
BLT-Mix occlusion-aware augmentation
```

也就是说，**主推理模型尽量简单**，增强复杂性放在训练阶段。这样更容易满足轻量实时检测的要求。

# 七、论文结构规划

## 摘要结构

摘要按这个逻辑写：

1. X-ray 安检图像存在重叠、伪色不稳定、小目标和细长目标难检测问题；
2. 现有 YOLO 类方法主要依赖 RGB 表观和常规增强，对 X-ray 透射特性利用不足；
3. 提出 EOA-YOLO：PCN + EGI + BLT-Mix；
4. 在 SPXray、PIDray、OPIXray 上验证；
5. 在 Hidden / Heavy / Small / Thin 场景提升明显，同时保持轻量实时。

## Introduction 结构

第一段：应用背景
X-ray 安检对公共安全重要，但违禁品经常被遮挡、重叠、伪装。

第二段：技术难点
伪色映射不稳定，目标纹理弱，小目标/细长目标容易漏检，普通 RGB 检测器不够稳。

第三段：现有方法不足
通用 YOLO/DETR 没有专门建模 X-ray 边缘结构；Copy-Paste/MixUp 不符合透射成像；注意力模块容易增加复杂度但收益不稳定。

第四段：你的方案
提出 PCN + EGI + BLT-Mix，分别解决伪色不稳定、边缘弱、遮挡样本不足。

第五段：贡献列表
建议写 3 条，不要写 4 条以上：

```text
1. We propose a pseudo-color normalized edge-guided input representation for X-ray prohibited item detection, which introduces structural edge cues without additional inference parameters.

2. We design BLT-Mix, an X-ray-oriented occlusion augmentation strategy based on local transmittance-like multiplicative composition and high-risk hue preservation.

3. Extensive experiments on SPXray, PIDray, and OPIXray demonstrate that the proposed method improves detection robustness for small, thin, hidden, and heavily occluded prohibited items while maintaining lightweight inference.
```

建议分三节：

1. **X-ray prohibited item detection**
   PIDray、OPIXray、SIXray、DOAM、Xray-YOLO-Mamba 等。
